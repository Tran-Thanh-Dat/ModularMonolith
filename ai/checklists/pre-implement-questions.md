# Pre-Implement Questions

Trả lời (ngắn) **trước khi** AI/dev viết code module/tính năng mới.

| # | Câu hỏi | Trả lời |
|---|---------|---------|
| 1 | Module/tính năng giải quyết nghiệp vụ gì? | |
| 2 | Entity chính? | |
| 3 | Actor nào dùng (Admin, User, …)? | |
| 4 | Cần permission nào (View/Create/Update/…)? | |
| 5 | Có status workflow (Draft/Active/…)? | |
| 6 | Soft delete? | |
| 7 | Cần cache read-heavy? | |
| 8 | Cần AuditLog + ActivityLog? | |
| 9 | Cần Files module (attach)? | |
| 10 | Cần Notification/Email? | |
| 11 | Cần BackgroundJob? | |
| 12 | Ownership/tenant/IDOR rules? | |
| 13 | List API: filter + pagination? | |
| 14 | Sort params có expose không? | |
| 15 | Out of scope? | |

Nếu cột trả lời trống → hỏi stakeholder hoặc ghi **Backlog** trước khi implement.
